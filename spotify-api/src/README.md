## Spotify Authorization ##
Begins on port 5173 acting as login page, rendered with 'showLoginPage()'. Once the button prompt is pressed on the login page the user is redirected to Spotify's login page, which is handled by Spotify. Spotify's login page is reached via the 'loginWithSpotify()' function, which creates the URL with requisite permissions and a code verifier and challenge.
Once login is successful, spotify calls a callback and re-runs the program, which uses the 'handleSpotifyCallback()' function which calls  'handleCallback()' which sends a post request to the running Node server ('server/server.js') on the backend, sending the server the verifier and auth code, which the server then uses to get the spotify access token and refresh token which are written into 'tokens.json'. The refresh token can be used to get a new access token without the need of re-logging in the user, though the refresh token will eventually expire as well.
